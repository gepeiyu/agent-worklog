# Agent Worklog

Use `agent-worklog summary` to read the local worklog and generate a report draft.
The installed worklog language is **{{WORKLOG_LANGUAGE}}**. Write turn summaries and any prose you add to report drafts in this language.

## Report workflow

1. Choose exactly one range form:
   - `agent-worklog summary --date YYYY-MM-DD`
   - `agent-worklog summary --week YYYY-MM-DD`
   - `agent-worklog summary --from YYYY-MM-DD --to YYYY-MM-DD`
2. Add `--platform` or `--project` only when the user asks for that filter.
3. Present the generated draft for human review. Never log in to, submit to, or modify an external company system.
4. Do not invent missing task summaries. Preserve the command's explicit missing-summary marker when a record has none.

## Turn summary protocol

When the hook-provided context requests a turn summary, write a concise sentence in **{{WORKLOG_LANGUAGE}}** describing only work actually completed in that turn. Put it in the requested `agent-worklog-summary` HTML comment. The summary must be your own account of the work, not text generated by a shell script.
